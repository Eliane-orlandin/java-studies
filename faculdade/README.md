## Criação de Packages e Classes no VS Code

- **Packages** servem para organizar o código em módulos e facilitar manutenção.
- No VS Code, com o _Java Extension Pack_ instalado:

  - Clique com o botão direito em `src` → **New Package**.
  - Digite o nome do pacote.
  - A estrutura de pastas é criada automaticamente.

- **Criando uma classe dentro do pacote**:

  - Clique com o botão direito no pacote → **New Java Class**.
  - O VS Code gera o arquivo já com a declaração de pacote no topo.
